## $${\color{#673AB7} \textbf{📁 \ Repositories}}$$

### 1. [**AWS_Tasks ☁️**](https://github.com/Gaurav1251/AWS_Tasks)

This repository is a collection of various AWS tasks, each demonstrating the deployment and configuration of different AWS services. 

### 2. [**DevOps_Tasks ♾️**](https://github.com/Gaurav1251/Devops_Tasks)
This repository organizes tasks related to various DevOps tools, including Docker, Kubernetes, Terraform, Jenkins, and Ansible. Each tool has a dedicated folder with tasks and instructions for efficiently managing your DevOps environment.


### 3. [**MovieTicketBoooking 🎬**](https://github.com/Gaurav1251/MovieTicketBoooking)
A Java-based web application for booking movie tickets, built with JSP, Servlets, HTML, CSS, JavaScript, and jQuery. It features user registration, movie listings, seat selection, and booking confirmation, along with an admin panel for managing movies and bookings. 

### 4. [**WeatherbyGk 🌤️**](https://github.com/Gaurav1251/WeatherbyGk)
A web application that provides weather forecasts for up to 7 days, created with HTML, CSS, and JavaScript. It fetches weather data from an API to display current weather conditions and forecasts for a specified location, offering a responsive and user-friendly interface. 

### 5. [**Devops_Tools_Install_Scripts 🛠️**](https://github.com/Gaurav1251/Devops_Tools_Install_Scripts)
A collection of automated scripts designed to streamline the installation and setup of essential DevOps tools.
